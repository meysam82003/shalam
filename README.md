# دیوان امتیاز

امتیازشمار آفلاین فارسی با طراحی سلطنتی سه‌بعدی برای **شلم**، **منفی** و **هزارتایی**.

## دریافت برنامه

آخرین APK نصب‌پذیر از صفحهٔ [Releases](https://github.com/meysam82003/shalam/releases/latest) قابل دریافت است.

## نسخهٔ سلطنتی ۲

- هویت بصری سرمه‌ای، طلایی، فیروزه‌ای و زرشکی بر اساس ۱۰ اطلس گرافیکی منتخب پروژه
- ۱۶ آواتار سه‌بعدی انیمیشنی ایرانی؛ بدون استفاده از پرتره‌های واقع‌گرای نسخهٔ قبلی
- فونت فارسی Vazirmatn، راست‌به‌چپ واقعی و پنل‌های متنی بدون نقش مزاحم پشت نوشته
- ذخیرهٔ خودکار، ادامهٔ بازی، تاریخچه، ویرایش و حذف هر دست

### شلم

- اعداد آماده: پاس، ۱۰۰، ۱۰۵، ۱۱۰، ۱۱۵ تا ۱۶۰، شلم و دبل‌شلم
- جریان دو مرحله‌ای: انتخاب تیم حاکم و تعهد، سپس ثبت امتیاز تیم حریف
- محاسبهٔ خودکار امتیاز واقعی حاکم از `۱۶۵ − امتیاز حریف`
- اگر امتیاز واقعی از تعهد کمتر باشد، تعهد به‌صورت منفی برای حاکم ثبت می‌شود
- تنظیمات امتیاز پایان، امتیاز شلم ۳۳۰/۴۰۰، حالت «فقط تعهد»، جوکر، دوبل و پایان با اختلاف

### منفی

- اعداد آماده از ۳ تا ۱۳ برای هر دو تیم
- ثبت پنهان عددها و نمایش سه نتیجهٔ ممکن پیش از تأیید
- برای نمونهٔ ۳ و ۱۰: `+۲۰ | +۳`، `+۲۰ | −۳` و `−۱۰ | +۳`
- امکان ویرایش نتیجهٔ هر دست و محاسبهٔ دوبارهٔ جمع‌ها

### هزارتایی

- امتیازدهی دوری، امتیاز منفی، جریمهٔ قابل تنظیم صفر و هدف ۱۰۰۰

## ساخت

پروژه با Java 17، Gradle 8.7 و Android SDK 35 ساخته می‌شود. تست و Build در GitHub Actions اجرا می‌شود و Push روی `main`، نسخهٔ `v2.0.0` را در Releases منتشر می‌کند.

فونت Vazirmatn تحت مجوز SIL Open Font License در `third_party_licenses` قرار دارد.
