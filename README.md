# دیوان امتیاز

امتیازشمار آفلاین و فارسی برای دورهمی‌های ورق با سه بازی **شلم**، **منفی** و **هزارتایی**.

## دریافت برنامه

نسخه نصب‌پذیر از صفحه [Releases](https://github.com/meysam82003/shalam/releases/latest) قابل دریافت است.

## امکانات

- رابط کاملاً فارسی و راست‌به‌چپ با طراحی سرمه‌ای، فیروزه‌ای و طلایی
- چهار آواتار سه‌بعدی اختصاصی
- ثبت امتیاز هر دست، جمع خودکار و بازگردانی آخرین دست
- ذخیره تاریخچه بازی‌ها تا ۱۰۰ مسابقه
- اجرای کاملاً آفلاین و بدون دسترسی اینترنت
- سازگار با Android 5.0 (API 21) و بالاتر

## ساخت

پروژه با Java 17، Gradle 8.7 و Android SDK 35 ساخته می‌شود. هر Push روی شاخه `main`، تست‌ها را اجرا و APK امضاشده را در Releases منتشر می‌کند.

> خروجی فعلی برای نصب مستقیم با کلید خودکار Build امضا می‌شود. برای انتشار فروشگاهی باید کلید خصوصی امن از طریق GitHub Secrets تنظیم شود.
