# تبلیغات

## قواعد ثابت (در کد، غیرقابل دور زدن از پنل)
- کاربر **Pro** هیچ تبلیغی نمی‌بیند. برای او هیچ تبلیغی انتخاب یا دانلود نمی‌شود و شبکهٔ تبلیغاتی اصلاً راه‌اندازی نمی‌شود. راه‌انداز خودکار تپسل از manifest حذف شده و فقط برای کاربر رایگان دستی اجرا می‌شود.
- تبلیغ فقط در جایگاه‌های امن نمایش داده می‌شود: خانه، تاریخچه، نتیجهٔ بازیِ پایان‌یافته، تنظیمات، و تمام‌صفحه پس از بستن نتیجه. هرگز روی صفحهٔ داوری، تایمر، شب و رأی‌گیری مافیا، نمایش نقش یا ثبت امتیاز نمایش داده نمی‌شود.
- هر تبلیغ برچسب «تبلیغات» دارد.
- ویدئوی جایزه‌ای فقط با انتخاب خود کاربر پخش می‌شود (پیش‌فرض: یک ساعت بدون تبلیغ).
- نمایش تبلیغ به‌طور پیش‌فرض **خاموش** است.

## تبلیغ مستقیم (از پنل)
پنل ← «تبلیغات ← تبلیغ جدید»:
- قالب‌ها: بنر کوچک، بنر افقی، کادر گوشه، کارت وسط صفحه، بنر تصویری، متنی، ویدئو، همسان با طراحی اپ، تمام‌صفحه، ویدئوی جایزه‌ای، اسپانسری.
- رسانه: JPG، PNG، WebP، GIF تا ۲ مگابایت و MP4 تا ۱۵ مگابایت. نوع واقعی فایل بررسی می‌شود. برنامه فایل را با کنترل SHA-256 دانلود و نگهداری می‌کند.
- تنظیمات هر تبلیغ: نشانی مقصد (فقط http/https عمومی)، زمان‌بندی، سقف روزانهٔ هر کاربر، سقف کل، فاصلهٔ کمینه، اولویت، فروشگاه (بازار/مایکت) و قابل بستن بودن.
- پیش‌نمایش زنده روی سه قاب گوشی (تیره، روشن، افقی) کنار فرم.

## تپسل (Tapsell Mediation)
- کتابخانهٔ تپسل فقط وقتی در APK قرار می‌گیرد که هنگام ساخت، **App ID** تپسل داده شود (متغیر گیت‌هاب `DIVAN_TAPSELL_APP_ID`). بدون آن، هیچ SDK تبلیغاتی در برنامه نیست و فقط تبلیغ مستقیم کار می‌کند.
- شناسهٔ تبلیغ‌گاه‌ها (بنر، همسان، تمام‌صفحه، جایزه‌ای) از پنل ← «شبکهٔ تبلیغاتی» قابل تغییر است.
- ترتیب منبع: اول مستقیم یا اول شبکه، یا فقط یکی از آن دو.
- تپسل API گزارش درآمد عمومی ندارد. درآمد را از پنل تپسل بخوانید و در «درآمد و عملکرد» با برچسب «واقعی» ثبت کنید. اعداد نمایش و کلیک را خود برنامه می‌شمارد و با برچسب «شمارش اپ» نشان داده می‌شود.
