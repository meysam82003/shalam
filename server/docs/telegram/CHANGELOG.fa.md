# تغییرات 1.0.0-rc3

- پیش‌نمایش خصوصی گزارش با سقف ۵۰۰ ردیف، کنترل هم‌زمان مجوز گزارش و مجوز بخش و ثبت Audit اضافه شد؛ داده یا فایل گزارش روی سرور عمومی ذخیره نمی‌شود.
- صفحه چاپ فارسی RTL؛ امکان ذخیره PDF فقط از امکانات چاپ مرورگر پشتیبان. CSV مستقل همچنان تا ۱۰هزار ردیف است.
- گزارش عملکرد تبلیغات، رسانه، پلن، کمپین، اعلان و بکاپ به انتخاب گزارش افزوده شدند؛ فیلترهای فهرست برای گزارش نیز استفاده می‌شوند.
- فیلتر اولویت تیکت، فعال/غیرفعال، درگاه سفارش و منبع/جایگاه تبلیغ اضافه شد؛ تاریخ معکوس رد می‌شود.
- صفحه‌بندی آمار هم‌روز و پلن‌های هم‌رتبه با کلید کامل مرتب می‌شود؛ آمار تبلیغ شناسه تبلیغ را فیلتر می‌کند و به ستون id ناموجود ارجاع نمی‌دهد.
- با تغییر فیلتر یا ترک صفحه، نتیجه قدیمی گزارش نمایش داده نمی‌شود؛ چاپ تنها گزارش را شامل می‌شود.
- نصب و تنظیم هاست طبق انتخاب مالک بر عهده خود او است؛ تحویل کد آزموده‌شده به معنای تأیید اتصال واقعی هاست نیست.

# تغییرات 1.0.0-rc2

- تمدید زمان اشتراک پس از پایان دوره‌های خرید و هدایا، با دوره مستقل رایگان؛ لغو فقط همان دوره مدیریتی. اعتبار خرید و تراکنش مالی تغییر نمی‌کند.
- قفل تراکنشی و شناسه یکتای درخواست از دو بار اعمال تمدید جلوگیری می‌کنند؛ نقش Support اجازه تمدید ندارد.
- بررسی آمادگی هاست و آزمایش خواندنی Telegram API/Webhook/Menu از پنل اضافه شد؛ خروجی محرمانه ندارد، نتیجه قدیمی پذیرفته نمی‌شود و تأیید Production جعل نمی‌شود.
- فرم نماد اعتماد سایت به همان SiteSettings و اعتبارسنجی موجود متصل شد؛ HTML ورودی اجرا یا ذخیره نمی‌شود.
- ورود و عملیات همچنان بدون رمز، کد یا تأیید امنیتی مجدد هستند.

# تغییرات 1.0.0-rc1

- ماژول Telegram با API مستقل، Bot خصوصی، پنل Owner و Mini App فارسی RTL افزوده شد.
- migration ۱۲ افزایشی: اعضا، پیوند اتصال، نشست، replay، درخواست idempotent، رویداد، صف، update، محدودیت نرخ و اولویت تیکت.
- ورود خودکار Telegram و تمدید بی‌صدای نشست فعال؛ طبق درخواست مالک، هیچ رمز/TOTP/تأیید امنیتی مجدد برای عملیات وجود ندارد. تأیید امضای تلگرام و نقش سروری پابرجاست.
- رویداد ثبت‌نام/پرداخت/Pro/پشتیبانی/کد/بکاپ/خطا به مسیر واقعی متصل شد؛ تماس تلگرام از مسیر خرید و ثبت‌نام خارج است.
- اعمال مشترک کاربر، هدیه، پلن و تبلیغ از سرویس/validator مشترک استفاده می‌کنند. Media و SiteSettings و منطق خرید فعلی حفظ شدند.
- حذف رسانه متصل به اعلان نیز در سرویس موجود مسدود شد.
- بکاپ اعضای تلگرام را رمزنگاری می‌کند؛ restore مجوزهای احیاشده را خاموش و نشست‌های پیشین را باطل می‌کند.
- UI شامل داشبورد، کاربر، فروش، پلن/کد/کمپین، تبلیغ/رسانه/جایگاه، اعلان polling، تیکت داخلی، محتوا/SEO، گزارش CSV و هشدار است.
- اصل فایل‌های سایت، APK، کد Android، کلیدهای Pro و endpoint پرداخت اپ تغییر نکرده‌اند. تغییرات purchase فقط ثبت رویداد و تراکنش DB متناظرند؛ مسیر استعلام معتبر حفظ شده است.

## آماده بهره‌برداری قطعی نیست

اتصال Telegram و Webhook روی هاست اصلی، نصب cPanel واقعی، نسخه DB سرور، کلاینت واقعی Telegram و موبایل اقتصادی تأیید نشده‌اند. PDF سروری، پاسخ‌رسانی تیکت به اپ، OAuth سرچ کنسول، Push لحظه‌ای، سقف دستگاه شخصی، انتقال/تغییر دلخواه خرید و relay تلگرام ساخته نشده‌اند. این موارد به‌عنوان قابلیت فعال معرفی نمی‌شوند. وضعیت آزمون مرورگر و Android در TEST-REPORT مشخص است.
