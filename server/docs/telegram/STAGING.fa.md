# نصب آزمایشی مستقل روی cPanel

این دستور برای تأیید بسته پیش از ارتقای نصب اصلی است. هیچ داده یا کلید Production را برای شروع لازم ندارد.

۱. در File Manager پوشه تازه `public_html/divan-tg-staging` بسازید و ZIP را داخل آن استخراج کنید. ساختار نهایی باید `public_html/divan-tg-staging/divan/` باشد. نصب اصلی `public_html/divan/` دست‌نخورده می‌ماند.
۲. پوشه والد مخصوص staging ضروری است: ابزار SEO فایل‌های کنار پوشه divan را بررسی/ویرایش می‌کند. نصب آزمایشی را مستقیماً با نام دیگری کنار divan اصلی نگذارید، چون والد آن همچنان ریشه سایت اصلی خواهد بود. برای آزمون SEO فقط کپی صفحات آزمایشی را در والد staging قرار دهید.
۳. با MySQL Database Wizard، دیتابیس و کاربر جدا بسازید. نصب‌کننده به دیتابیس خالی staging متصل شود؛ config، کلیدها و DB اصلی کپی نشوند. نام کاربر/رمز دیتابیس فقط در همان نصب‌کننده ثبت شوند.
۴. آدرس مبنا در نصب‌کننده: `https://httpuser87890.ir/divan-tg-staging/divan`. حساب مدیر آزمایشی را از نصب‌کننده موجود بسازید؛ کلیدهای ساخته‌شده فقط به این نصب تعلق دارند.
۵. از یک ربات اختصاصی آزمایش استفاده کنید؛ توکن ربات فعال Production را به staging ندهید، چون setWebhook مقصد دریافت آن ربات را تغییر می‌دهد. توکن فقط از بخش «مدیریت تلگرام» همین پنل ذخیره شود.
۶. اتصال مالک، آزمایش API، ثبت Webhook و دکمه Mini App را در همین پنل انجام دهید. نشانی Mini App باید `https://httpuser87890.ir/divan-tg-staging/divan/tg/app/` باشد.
۷. Cron جدید فقط به `public_html/divan-tg-staging/divan/tg/worker.php` اشاره کند. Cronهای نصب اصلی و تنظیمات درگاه اصلی تغییر نکنند.
۸. بررسی آمادگی نصب را اجرا کنید. ثبت‌نام/هدیه/تمدید/رسانه/تیکت فقط با داده مصنوعی در DB آزمایشی انجام شود. مسیرهای پرداخت فقط با sandbox رسمی یا آزمون‌های محلی موجود بررسی شوند؛ درگاه واقعی و پول واقعی برای آزمون استفاده نشود.
۹. بازکردن مینی‌اپ در Telegram واقعی، دریافت یک‌باره اعلان، خروجی CSV، لغو مدیر و رفتار صف هنگام قطع شبکه بررسی و نتایج ثبت شوند. صرف موفقیت صفحه داشبورد یا تست getMe برای تأیید نهایی کافی نیست.
۱۰. پس از قبولی، تفاوت فایل‌های Production با commit مبنا، نسخه PHP و migrationهای اصلی را تطبیق دهید. سپس با بکاپ مستقل و طبق INSTALL.fa.md ارتقا انجام شود. این راهنما به‌تنهایی به معنی تأیید یا انجام ارتقای اصلی نیست.
