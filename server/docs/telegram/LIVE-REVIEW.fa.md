# بازبینی نصب واقعی — ۱۴۰۵/۰۷/۲۶

ورود به پنل وب از مرورگر با نقش مدیر اصلی تأیید شد. بررسی فقط خواندنی بود؛ هیچ فرم مدیریتی، خرید یا تغییر تنظیمات از طرف عامل ارسال نشد.

- داشبورد، کاربران، تبلیغات و جایگاه‌ها قابل مشاهده‌اند.
- قالب‌ها و ۱۸ جایگاه تبلیغ با ساختار سورس مبنا تطبیق دارند؛ محدودیت نمایش در صفحه داوری/تایمر و قالب‌های مخصوص سایت برقرار است.
- تنظیمات دانلود سایت نسخه ۵.۵.۱ را اعلام می‌کند؛ این مقدار، نسخه دقیق فایل‌های PHP یا ساختار دیتابیس را ثابت نمی‌کند.
- بخش مدیریت سایت شامل متن، تماس، دانلود، بخش‌ها، بنر و اینماد است. فرم اینماد در مینی‌اپ به اعتبارسنجی مشترک متصل شد.
- بخش مدیریت تلگرام در منوی مالک نصب فعلی مشاهده نشد.
- پنل فعلی ابزار نصب فایل‌های ماژول یا ساخت دیتابیس staging ندارد. برای ادامه، ورود cPanel یا ابزار رسمی مدیریت هاست لازم است.

نسخه PHP، migrationهای واقعی دیتابیس، تفاوت فایل‌های هاست با سورس، دسترسی شبکه هاست به Telegram API و عملکرد Webhook هنوز بررسی نشده‌اند. اتصال پنل وب به‌تنهایی این موارد را تأیید نمی‌کند. نصب و آزمایش باید ابتدا در مسیر و دیتابیس مستقل انجام شود؛ توکن ربات در تنظیمات همان محیط ثبت شود. اعتبارسنجی staging بدون ارسال پول واقعی و بدون داده مصنوعی در Production انجام می‌شود.
