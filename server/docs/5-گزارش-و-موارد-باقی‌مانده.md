# گزارش تحویل نسخهٔ ۵.۱.۰ — اشتراک Pro، پرداخت، تبلیغات و پنل

## آزمون‌های انجام‌شده (با شواهد)

| آزمون | نتیجه |
|---|---|
| آزمون خودکار سرور `server/tests/run.php` روی MariaDB واقعی با فروشگاه شبیه‌سازی‌شده | **۱۲۳ از ۱۲۳ موفق**؛ در هر ساخت گیت‌هاب هم اجرا می‌شود |
| آزمون‌های واحد اپ (بازی‌ها + اشتراک) | ۱۰۸ از ۱۰۸ موفق |
| آزمون دود (smoke) رابط کاربری اپ (Robolectric) | ۱۳ از ۱۳ موفق |

| همهٔ ۲۱ صفحهٔ پنل با ورود دومرحله‌ای واقعی | بدون خطا |
| کامپایل کد بازار (Poolakey 2.2.0)، مایکت (1.19) و تپسل (1.3.0) با کتابخانه‌های واقعی | موفق |

  - قفل همگام‌سازی قیمت
  - کمپین واقعی
  - توکن تخفیف پویای بازار
- **گواهی و تک‌گوشی:**
  - گواهی آفلاین، گواهی دست‌کاری‌شده و پنجرهٔ آفلاین
  - قانون تک‌گوشی، انتقال و سقف انتقال

- **قابلیت‌ها و تبلیغات:**

  - پشتیبان رمزنگاری‌شده و بازگردانی بدون بازنویسی دادهٔ تازه‌تر
  - پشتیبانی و محدودیت ارسال

## تست‌نشده (نیازمند حساب‌ها و کلیدهای واقعی مالک)
- **پرداخت واقعی در کافه‌بازار و مایکت:** نیازمند محصولات تعریف‌شده در پنل فروشگاه و نصب APK امضاشده از فروشگاه است. کد کامپایل شده و منطق با فروشگاه شبیه‌سازی‌شده آزموده شده، ولی هیچ پرداخت واقعی انجام نشده است.
- **پاسخ واقعی API صحت‌سنجی بازار و مایکت:** کلید API در دست نیست. ساختار درخواست‌ها طبق مستندات رسمی است.
- **تبلیغات تپسل:** App ID و تبلیغ‌گاه واقعی در دست نیست. راه‌اندازی دستی SDK از کلاس داخلی تپسل استفاده می‌کند و باید با کلید واقعی آزموده شود. بدون App ID، تپسل در APK نیست.
- **نصب روی هاست واقعی `httpuser87890.ir`:** دسترسی cPanel در دست نیست. نصب روی محیط مشابه (PHP 8.3 و MariaDB) آزموده شده است.
- **اتصال گوشی‌های اندروید ۵ تا ۷ به سرور:** ریشه‌های ISRG همراه برنامه است، ولی روی گوشی واقعی آزموده نشده است.
- **رفتار در اینترنت ملی:** شبیه‌سازی شد (سرور در دسترس نیست → Pro از گواهی آفلاین). روی شبکهٔ واقعی آزموده نشده است.

## اطلاعاتی که مالک باید فراهم کند

| مورد | کجا ثبت شود | محرمانه؟ |
|---|---|---|
| اطلاعات پایگاه دادهٔ هاست | نصب‌کنندهٔ وب | بله؛ فقط روی هاست |
| کلید API پیشخوان بازار (یا OAuth) | پنل ← بازار و مایکت | بله؛ رمزنگاری‌شده در پایگاه داده |
| کلید عمومی RSA پرداخت بازار | پنل ← بازار و مایکت | خیر |
| کلید تخفیف پویای بازار (اختیاری) | پنل ← بازار و مایکت | بله |
| توکن API مایکت | پنل ← بازار و مایکت | بله |
| کلید عمومی RSA مایکت | پنل و متغیر گیت‌هاب `DIVAN_MYKET_RSA_KEY` | خیر |
| App ID تپسل (اختیاری) | متغیر گیت‌هاب `DIVAN_TAPSELL_APP_ID` | خیر |
| شناسهٔ تبلیغ‌گاه‌های تپسل | پنل ← شبکهٔ تبلیغاتی | خیر |
| تعریف ۴ محصول و قیمت‌ها در پنل هر فروشگاه | پنل بازار و پنل مایکت | — |
| افزایش سقف قیمت بازار برای ۲۲۰٬۰۰۰ تومان | پشتیبانی بازار | — |
| کلید عمومی امضای گواهی سرور برای سنجاق در برنامه (اختیاری، امنیت بیشتر) | پنل: `api/index.php?r=v1/keys` ← متغیر گیت‌هاب `DIVAN_LICENSE_KEY` | خیر |

هیچ کلید خصوصی، رمز یا توکنی در گیت‌هاب ذخیره نشده است.

## موارد مسدود یا وابسته به تصمیم مالک
1. **محل هاست:** هاست فعلی در هلند است. برای کار در زمان اینترنت ملی، هاست ایران لازم است (راهنمای نصب).
2. **انتشار در بازار و مایکت:** طبق دستور، بدون اجازهٔ صریح انجام نشده است.
3. **کمپین تبلیغاتی پولی:** هیچ کمپینی فعال نشده و نمایش تبلیغ در تنظیمات پیش‌فرض خاموش است.
4. **مجوز اینترنت:** نسخهٔ ۵.۱.۰ برای اشتراک، قیمت‌ها و تبلیغات مجوز INTERNET دارد. فروشگاه‌ها این مجوز تازه را به کاربران نشان می‌دهند.
