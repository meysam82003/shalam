# سایت رسمی — اطلاعاتی که مالک باید وارد کند

سایت معرفی (پوشهٔ `site/` ← `public_html` هاست) برای بررسی بانک‌ها و کاربران کامل شده است. اطلاعات هویتی و تماس **از خود سایت ساخته نشده** و هر فیلد خالی روی سایت پنهان می‌ماند، نه اینکه جای آن متن ساختگی نشان داده شود.

## ۱. فایل تنظیمات: `site-assets/js/site-config.js`

فقط همین یک فایل را ویرایش و در `public_html/site-assets/js/` آپلود کنید.

| فیلد | چه چیزی وارد شود | کجا دیده می‌شود |
|---|---|---|
| `business.owner` | نام صاحب امتیاز، **دقیقاً مطابق پروندهٔ اینماد** | پاورقی همهٔ صفحه‌ها، «دربارهٔ ما»، دادهٔ ساختاریافتهٔ Organization |
| `business.ownerType` | «حقیقی» یا «حقوقی» | «دربارهٔ ما» |
| `business.registration` | شناسهٔ ملی یا شمارهٔ ثبت شرکت (فقط حقوقی) | «دربارهٔ ما» |
| `business.since` | سال شروع فعالیت | «دربارهٔ ما» |
| `contact.email` | ایمیل پشتیبانی (اکنون: meysamsalamatnasab@gmail.com) | همهٔ صفحه‌ها |
| `contact.phone` | تلفن ثابت ثبت‌شده در اینماد با کد شهر | همهٔ صفحه‌ها |
| `contact.mobile` | تلفن همراه پشتیبانی (اختیاری) | «تماس با ما» |
| `contact.address` و `contact.postalCode` | نشانی و کد پستی ثبت‌شده در اینماد | همهٔ صفحه‌ها، «تماس با ما» |
| `contact.hours` | ساعات پاسخ‌گویی | «تماس با ما» |
| `contact.telegram` / `eitaa` / `bale` | نام کاربری پشتیبانی بدون @ (اختیاری) | «تماس با ما» |
| `downloads.*` | پس از هر انتشار تأییدشده: نشانی، حجم و SHA-256 هر فایل | صفحهٔ «دریافت دیوان امتیاز» |

تا وقتی `url` یک نسخه خالی است، دکمهٔ آن «به‌زودی» نشان داده می‌شود و پیوندی ندارد.

## ۲. نماد اعتماد الکترونیکی (اینماد)

- کد را **فقط از پنل رسمی enamad.ir** همان دامنه کپی کنید و بدون تغییر بین دو خط `ENAMAD-START` و `ENAMAD-END` بگذارید:
  - `index.html` (پاورقی؛ الزامی، چون اینماد صفحهٔ اصلی را بررسی می‌کند)
  - `contact.html` (اختیاری)
- بخش «نماد اعتماد» صفحهٔ تماس تا وقتی کدی گذاشته نشده پنهان است.
- **بررسی‌نشده:** سایت enamad.ir از خارج ایران در دسترس نبود. به همین دلیل اعتبار نماد و ارتباط آن با دامنه و کسب‌وکار از این محیط بررسی نشد. پس از نصب کد، روی نماد کلیک کنید و مطمئن شوید صفحهٔ اینماد نام دامنهٔ `httpuser87890.ir` و همان نام صاحب امتیاز را نشان می‌دهد.
- نام، تلفن و نشانی فایل تنظیمات باید با پروندهٔ اینماد یکی باشد.

## ۳. صفحه‌های سایت

| صفحه | محتوا |
|---|---|
| `index.html` | معرفی، بازی‌ها، نمای برنامه، امکانات، Pro، پرسش‌ها، دریافت |
| `download.html` | «دریافت دیوان امتیاز»: اندروید سایت، بازار، مایکت، آیفون و آیپد، ویندوز، وب؛ مقایسه و راهنمای نصب |
| `pro.html` | شرایط خرید اشتراک Pro: پلن‌ها، پرداخت در هر نسخه، فعال‌سازی، یک دستگاه، مادام‌العمر |
| `refund.html` | قوانین لغو و بازگشت وجه |
| `terms.html` | شرایط استفاده |
| `privacy.html` | حریم خصوصی (شامل نسخهٔ وب و پرداخت‌ها) |
| `about.html` | معرفی رسمی و هویت کسب‌وکار |
| `contact.html` | راه‌های تماس، پیگیری خرید، نماد اعتماد |

دادهٔ ساختاریافته برای موتورهای جست‌وجو (WebSite، SoftwareApplication با قیمت پلن‌ها، FAQPage، BreadcrumbList و Organization)، نشانی canonical، Open Graph، نقشهٔ سایت و فونت فشردهٔ WOFF2 اضافه شده است.

## ۴. نصب به‌روزرسانی سایت

فقط فایل‌های تغییرکرده را در `public_html` جایگزین کنید. به پوشهٔ `divan`، به `index.php.old` و به تنظیمات هاست دست نزنید. فایل `.htaccess` تازه همان قواعد قبلی را دارد به‌اضافهٔ نوع درست فایل‌های `.mobileconfig`، `.apk` و `.webmanifest` و کش فونت‌ها. اگر قبلاً `.htaccess` ریشه را تغییر داده‌اید، فقط دو بلوک `mod_mime` و `mod_expires` را به آن اضافه کنید.
