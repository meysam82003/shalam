# راهنمای نصب سرور دیوان امتیاز روی هاست

سرور اشتراک، API برنامه، سایت و پنل مدیریت در یک فایل ZIP است و هیچ نیازی به ترمینال، Composer یا NPM ندارد.

## پیش‌نیازهای هاست (حداقل)

| مورد | حداقل | پیشنهاد |
|---|---|---|
| PHP | 7.4 | 8.1 یا 8.2 |
| افزونه‌های PHP | pdo_mysql، openssl، curl، json، mbstring، fileinfo، gd، zlib | همین‌ها |
| پایگاه داده | MySQL 5.7 یا MariaDB 10.3 | MariaDB 10.6+ |
| فضا | ۳۰۰ مگابایت | ۱ گیگابایت (برای پشتیبان‌ها و رسانهٔ تبلیغات) |
| SSL | گواهی معتبر HTTPS (Let's Encrypt یا AutoSSL کافی است) | — |
| Cron Job | اختیاری | روزانه |
| آپاچی/لایت‌اسپید | پشتیبانی از `.htaccess` | — |

### هاست ایران یا خارج؟
دامنهٔ فعلی (`httpuser87890.ir`) روی سروری در **هلند** است. در زمان قطع اینترنت بین‌الملل (اینترنت ملی)، گوشی‌های ایران به این سرور دسترسی ندارند:
- بازی‌ها و تاریخچه آسیبی نمی‌بینند (همه‌چیز روی گوشی است).
- Pro تا پایان اعتبار آفلاین گواهی (پیش‌فرض ۷ روز برای اشتراک زمان‌دار و ۳۰ روز برای مادام‌العمر) کار می‌کند.
- خرید تازه، ورود، بازیابی و انتقال گوشی ممکن نیست. رسید خریدهایی که در این مدت انجام شوند روی گوشی نگه داشته می‌شود و بعداً ثبت می‌شود.

برای کار کامل در زمان اینترنت ملی، سرور باید روی **هاست ایران** (دیتاسنتر داخل کشور، IP ایران) باشد. همان ZIP بدون تغییر روی هاست ایرانی نصب می‌شود. پس از جابه‌جایی، نشانی API را در ساخت برنامه عوض کنید (متغیر `DIVAN_API`) یا همان دامنه را به هاست ایران منتقل کنید. توجه: سرور برای بررسی خرید باید به API بازار و مایکت دسترسی داشته باشد؛ این دو سرویس ایرانی‌اند و از هاست ایران در دسترس‌ترند.

## مراحل نصب

1. در cPanel یا DirectAdmin یک **پایگاه دادهٔ MySQL** و یک **کاربر** بسازید و همهٔ دسترسی‌ها را به کاربر بدهید. نام پایگاه، نام کاربر و رمز را یادداشت کنید.
2. فایل `Divan-Emtiaz-Web-Installer.zip` را با File Manager در `public_html` بارگذاری کنید و **Extract** را بزنید. پوشه‌ای به نام `divan` ساخته می‌شود. پوشه‌های فعلی هاست دست نمی‌خورند.
3. در مرورگر `https://دامنه/divan/install/` را باز کنید.
4. **مرحلهٔ ۱ (بررسی هاست):** نسخهٔ PHP، افزونه‌ها، HTTPS، قابل‌نوشتن بودن پوشه‌ها و امکان ساخت کلید RSA بررسی می‌شود. اگر موردی قرمز بود، از پشتیبانی هاست بخواهید آن را فعال کند.
5. **مرحلهٔ ۲ (پایگاه داده):** فقط نام پایگاه، نام کاربر و رمز را وارد کنید. جدول‌ها ساخته و کلیدهای رمزنگاری و امضا تولید می‌شوند.
6. **مرحلهٔ ۳ (مدیر اصلی):** نام کاربری و رمز قوی (۱۲ نویسه یا بیشتر، با حرف بزرگ، حرف کوچک و رقم) وارد کنید. QR را با Google Authenticator، Microsoft Authenticator یا Aegis اسکن کنید و کد شش‌رقمی را بنویسید.
7. **مرحلهٔ ۴ (پایان):** **کلید پشتیبان** نمایش داده می‌شود. آن را بیرون از هاست نگه دارید (کاغذ یا مدیر رمز). نصب‌کننده خودش را قفل می‌کند و دیگر قابل اجرا نیست.

نشانی‌ها پس از نصب:
- پنل مدیریت: `https://دامنه/divan/admin/`
- API برنامه: `https://دامنه/divan/api/index.php`
- سایت عمومی (معرفی، حریم خصوصی، شرایط، حساب، پشتیبانی): `https://دامنه/divan/`

## Cron Job (پیشنهادی)
در cPanel ← Cron Jobs، یک بار در روز:
```
php /home/USER/public_html/divan/cron.php
```
یا با نشانی (کلید در صفحهٔ «پشتیبان‌گیری» پنل نمایش داده می‌شود):
```
curl -s "https://دامنه/divan/cron.php?key=CRON_KEY" >/dev/null
```
این کار پشتیبان روزانهٔ رمزنگاری‌شده می‌گیرد، خریدهای در انتظار و بازپرداخت‌ها را با فروشگاه‌ها بررسی می‌کند و جدول‌های موقت را پاک می‌کند. اگر Cron نسازید، همین کار هنگام ورود مدیر به پنل (حداکثر ساعتی یک بار) انجام می‌شود.

## به‌روزرسانی
ZIP نسخهٔ تازه را روی همان پوشه Extract کنید (پوشهٔ `storage` و `media` بازنویسی نمی‌شود چون در ZIP فایل تنظیمات ندارند). تغییرات پایگاه داده (migration) با اولین باز شدن پنل یا API خودکار و بدون حذف داده اعمال می‌شود.

## امنیت
- پوشه‌های `app` و `storage` با `.htaccess` از دسترس وب بسته‌اند. پس از نصب، `https://دامنه/divan/storage/config.php` باید خطای 403 بدهد؛ این را یک بار امتحان کنید.
- اجرای PHP در پوشهٔ `media` (فایل‌های تبلیغات) بسته است.
- کلید خصوصی امضای گواهی‌ها فقط در `storage/keys` روی سرور است و هرگز در برنامه یا گیت‌هاب قرار نمی‌گیرد.
- رمزها با Argon2id/bcrypt درهم‌سازی و کلیدهای فروشگاه با AES-256-GCM رمزنگاری می‌شوند.
