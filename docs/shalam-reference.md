# مبنای رفتاری شلم

این پروژه کد یا دارایی APK مرجع را کپی نمی‌کند. APK ارسالی «شلم‌شمار» فقط برای شناسایی جریان‌ها، عنوان تنظیمات و رفتار امتیازدهی بررسی شده است.

مواردی که از APK مرجع تثبیت شدند:

- «امتیاز خوانده‌شده»، «امتیاز تیم حاکم» و «امتیاز تیم حریف» سه مفهوم جدا هستند.
- امتیاز شلم می‌تواند ۳۳۰ یا ۴۰۰ باشد.
- حالت «تیم حاکم در صورت برنده شدن فقط امتیاز تعهد را می‌گیرد» تنظیمی اختیاری است.
- گزینه‌های جوکر، دوبل مثبت/منفی، پرسش هنگام بازی، پایان بازی با اختلاف و ویرایش دست وجود دارند.
- هر دست باید قابل ویرایش یا حذف باشد و جمع‌ها پس از تغییر دوباره محاسبه شوند.

قانون قطعی اعمال‌شده بر اساس اصلاح کاربر:

1. امتیاز کل دست ۱۶۵ است.
2. پس از ثبت تعهد، فقط امتیاز حریف وارد می‌شود.
3. امتیاز واقعی حاکم برابر `۱۶۵ − امتیاز حریف` است.
4. اگر امتیاز واقعی حاکم کمتر از تعهد باشد، امتیاز حاکم `−تعهد` می‌شود و امتیاز حریف حفظ می‌شود.
5. اگر به تعهد برسد، امتیاز واقعی حاکم و امتیاز حریف هر دو ثبت می‌شوند؛ مگر اینکه گزینهٔ «فقط تعهد» فعال باشد.

نمونه‌های آزموده‌شده:

- تعهد ۱۳۵، حریف ۳۵ → واقعی حاکم ۱۳۰ → حاکم −۱۳۵، حریف ۳۵.
- تعهد ۱۳۵، حریف ۱۵ → واقعی حاکم ۱۵۰ → حاکم ۱۵۰، حریف ۱۵.
